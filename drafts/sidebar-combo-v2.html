What changes vs. v1
  • Compact projects = just the colored dot, not a full filled circle. Matches the look you already have in the full sidebar — same dot, just centered on its own row.
  • Active project in compact mode: dot gets a soft white outer ring (instead of becoming a filled disc). Subtle background tint behind it.
  • Workspace icons stay as their existing colorful glyphs (✅🤝📝✨🔔📤🔀…), centered. No restyling.
  • Overdue / today badges: tiny 14px red/amber bubble in the top-right corner of the project's slot — only when there's actually something. Same for Todos nav item (4 overdue → red bubble).
  • Active nav item: 3px accent stripe on the left edge of the slot, plus light tinted background. No box, no fill — keeps the rail visually quiet.
  • Pinned items in compact: just the type icon (✓ 📝 🔀 ●) centered. Hover tooltip shows the full title.
  • Overview button shrinks to a 36px square with just the ◈ glyph.
Drag mechanics Reuse setupSidebarResizer: when computed width drops below ~110px, add body.sidebar-compact. The CSS class flip swaps to compact rules. No animation needed (the resize itself is the animation). Width is persisted in localStorage as today.
