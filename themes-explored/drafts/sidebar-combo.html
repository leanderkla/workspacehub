How the combo works Three sections, top to bottom:
  • ⭐ Pinned — your hand-picked items (todos / notes / flows / projects). Right-click anywhere in the app to "Pin to sidebar". Hover shows the ★ to unpin. Cross-type — your most-touched flow sits next to your most-checked todo.
  • Projects — lean cards. Each shows project name + an alert pill only if there's something urgent:
    • ⚠ 4 red pill when overdue items exist
    • 📅 1 amber pill when only "due today" items exist
    • Nothing when the project is clean — keeps the rail visually quiet
    Active project gets a soft accent fill. Urgent projects get a red gradient bleed from the left so even a clean glance reveals trouble.
  • Workspace nav — same items as today (Dashboard, Notes, Todos, Commitments, Delegations, Flows, Subprojects, Spark Map, Reminders). Todos still gets the red overdue count.
Drag-collapse Reuse your existing sidebar resizer. When the user drags below ~110px, a CSS class swaps in:
  • Pins → just their type icons
  • Projects → colored dots with overdue count as a small red bubble in the corner
  • Nav → just glyphs with red count bubble for Todos
  • Section labels hidden
All hover-tooltips still work. No magic auto-expand on hover (you specifically chose this — drag is intentional).
